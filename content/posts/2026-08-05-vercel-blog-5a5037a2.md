Meta 的 Muse Spark 1.2 现已上线 AI Gateway。这是对先前 Muse Spark 模型的编码聚焦更新。在保留其通用能力的同时，1.2 版本在代码生成、复杂调试、代码库理解和端到端开发者工作流方面均有改进。

该模型专为长周期任务而构建，例如生成整个代码仓库、端到端搭建大型项目，以及维持迭代循环——在循环中它能够多轮编写、编译、分析性能并改进代码。

要在 AI SDK 中使用 Muse Spark 1.2，请将模型设置为 `meta/muse-spark-1.2`：

```
1import { streamText } from 'ai';2
3const result = streamText({4  model: 'meta/muse-spark-1.2',5  prompt: '将此服务从已弃用的 API 迁移出来。',6});
```

要在编码 Agent 中使用 Muse Spark，请运行 `vercel ai-gateway coding-agents setup` 以连接 Claude Code、Codex、OpenCode 或 Pi，然后在 Agent 内选择 `meta/muse-spark-1.2`。

AI Gateway 提供统一 API，用于调用模型、跟踪使用量和成本，并配置重试、故障转移和性能优化，以实现高于提供商自身的可用性。它还内置了自定义报告、零数据保留支持、API 密钥预算、路由规则等功能。

AI Gateway 反映提供商定价，不加价，且不对推理收取平台费用，包括自带密钥（BYOK）请求。
