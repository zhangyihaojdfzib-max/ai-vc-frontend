Hermes Agent 现在可以使用 Vercel AI Gateway 作为其推理层，并在隔离的 Vercel Sandbox 微虚拟机中运行其 Agent 命令。通过 AI Gateway 可访问 200 多个模型，Token 无加价，每个请求都会与您的其他用量和支出一起显示在 AI Gateway 仪表盘中。

### 复制链接到标题 设置

安装 Hermes，然后在设置向导中选择 Vercel AI Gateway：

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

hermes updatehermes setup model      hermes setup terminal   
hermes doctor
```

选择器会从 AI Gateway 实时拉取模型可用性和当前定价。完整操作指南请参阅配置 Hermes。

### 复制链接到标题 在 Vercel Sandbox 中运行命令

Vercel Sandbox 后端为可选启用。在将 `terminal.backend` 设置为 `vercel_sandbox` 之前，命令均在本地运行；启用后，Agent 命令将在云端微虚拟机中运行，工作区根目录为 `/vercel/sandbox`，而非在您的本机运行。该后端支持 `node24`（默认）、`node22` 和 `python3.13` 运行时。对于本地开发，请使用 `VERCEL_OIDC_TOKEN`。运行 `vercel link` 和 `vercel env pull` 以获取开发令牌。

要开始使用，请阅读 Hermes 文档和 Vercel Sandbox 文档，或浏览 AI Gateway 模型。
