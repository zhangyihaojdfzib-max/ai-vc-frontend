You can now createeveagents directly from the Vercel dashboard, giving you a deployed agent that you can chat with right away. The builder scaffolds the agent, creates a private Git repository with its files, and deploys it as a new Vercel project on your team. In a few clicks, you get a working agent, backed by a repo with code you can use to customize it.

From the builder you can:

- Write the instructions that define the agent's identity
- Pick any model available throughAI Gateway
- Add a Next.js web chat or Slack channel where people can talk to the agent
- Give the agent tools and data from other services through built-in connections like Linear and Notion, or a custom MCP server
