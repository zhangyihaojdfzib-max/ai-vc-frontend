Exaweb 搜索现在在 AI Gateway 上免费开放至 8 月 31 日，并且它现已成为 eve 的默认网页搜索工具。

该工具适用于任何 AI Gateway 模型，无需单独的 Exa API 密钥。当模型调用它时，AI Gateway 会将请求路由至 Exa 的 Search API，返回网页结果和提取的页面内容，并支持域名筛选、日期筛选和高效 Token 摘要。

当模型通过 AI Gateway 提供服务时，eve 内置的 `web_search` 工具现在默认使用 Exa。有关其他受支持的搜索配置，请参阅 eve 文档。

要将其与 AI SDK 配合使用，请将 `gateway.tools.exaSearch()` 传递给 `generateText` 调用的 `tools` 参数：

```
1import { gateway, generateText, stepCountIs } from 'ai';2const { text } = await generateText({3  model: 'openai/gpt-5.6-terra',4  prompt: 'What are the latest developments in AI this week?',5  tools: {6    exa_search: gateway.tools.exaSearch(),7  },8  stopWhen: stepCountIs(3),9});
```

使用 Exa 网页搜索在多个工具步骤中回答提示词

阅读网页搜索文档以了解更多信息并开始使用。
