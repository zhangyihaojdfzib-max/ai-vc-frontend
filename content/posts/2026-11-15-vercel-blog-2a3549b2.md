Qwen4-Max from Alibabais now available on AI Gateway. It is the first model in the Qwen4 series: a reasoning model with native vision and a 1M-token context window, built for coding, professional work, and long-running agent tasks.

Qwen4-Max is better at working with professional tools. It can build 3D scenes in Blender and playable games in Unity, Unreal Engine, and Godot, running what it builds and using visual feedback to fix camera, animation, and lighting issues. For finance, legal, and healthcare work, it can call many MCP tools, work through large sets of documents and images, and produce spreadsheets, slide decks, and reports that cite their sources.

For long-running tasks, the model delivers a usable first version early and then improves it in successive releases, so you can review progress and change direction before the work is finished. Alibaba is open-sourcing a Live Delivery plugin for this workflow. Compared with prior Qwen Max models, Qwen4-Max uses fewer tokens to complete the same tasks and writes more secure code by default, with fewer injection, memory safety, and access control vulnerabilities.
