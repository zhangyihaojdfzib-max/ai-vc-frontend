DeepSeek V4 Pro 现已在 AI Gateway 上使用更新后的权重运行。当您调用 `deepseek/deepseek-v4-pro` 时，默认会使用这些新权重，因此现有请求无需更改模型 ID 或代码即可自动生效。

要使用更新后的 DeepSeek V4 Pro，请在 AI SDK 中将模型设置为 `deepseek/deepseek-v4-pro-0813`。AI Gateway 会将请求路由到使用新权重的提供商：

```
1import { streamText } from 'ai';
2
3const result = streamText({
4  model: 'deepseek/deepseek-v4-pro-0831',
5  prompt: '修复此仓库中失败的测试并提交一个 PR。',
6});
```

要在编码 Agent 中运行 V4 Pro，请使用 `vercel ai-gateway coding-agents setup` 将您的 Agent 连接到 AI Gateway，然后在 Agent 的模型配置中选择 `deepseek/deepseek-v4-pro-0813`。请参阅编码 Agent 指南。

AI Gateway 以提供商价格直接提供服务，不加价，且不对推理收取平台费用，包括自带密钥（BYOK）请求。了解更多关于 AI Gateway 的信息，查看 AI Gateway 模型排行榜，或在我们的模型游乐场中试用。
