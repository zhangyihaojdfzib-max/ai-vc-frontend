Do we grow software or do we design it?

Vibe-coding is growing software. Start with the germ of the idea. Iterate on it. Let’s try this. Poke the petri dish with a bit of glucose ; oh, that didn’t work. Maybe some thymol blue to see if the colony is alive? Time to start again.

The most sophisticated vibe-coders test with 4-5 different petri dishes in parallel & pick the one whose bacteria have evolved optimally.

Designed software in the AI era is state machine design : flow charts that work. First, the email comes in. Three options : archive, add to the CRM, or escalate to a person. If adding to the CRM, determine the company’s stage.

When co-designing a state machine with AI, ask for the flowchart. The AI willingly shares schematics. Lay out every fork in a table with the right outcome. The holes jump out immediately. Plus, formal verification proves the software will work as intended.
