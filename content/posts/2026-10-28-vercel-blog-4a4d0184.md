Vercel Container Registrynow supports up to 2 GB per compressed image layer, up from 500 MB, allowing larger layers to be pushed without splitting them. The total image size limit remains 15 GB.

The higher layer limit is useful for images with large toolchains or dependency sets, such as customVercel Sandboxenvironments for coding-agent evaluations.

With Docker and theVercel CLIinstalled, run these commands from the directory containing your Dockerfile:

```
vercel linkvercel vcr login dockervercel vcr build docker . --push
```

Link your project, authenticate Docker, then build and push the image.

Read theVercel Container Registry getting-started guideto build, push, and pull your first container image.
