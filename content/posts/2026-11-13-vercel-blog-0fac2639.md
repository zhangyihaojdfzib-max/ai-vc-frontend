You can now scan code changes for vulnerabilities withVercel Security Reviewin GitHub repositories that have not yet been linked to a Vercel project.

By default, Security Review covers all unlinked repositories the Vercel GitHub App can access in a connected GitHub account. You can limit coverage to selected connected accounts or individual repositories in Agent settings. Once enabled, each push to a covered repository automatically triggers a review of its code changes.

Security Review checks commits directly in repositories with Security Review enabled, without requiring a Vercel project or deployment. When a push creates a deployment for a linked project with Security Review enabled, the review uses the additional project and deployment context.

Connect the account in your team’sGit settings, then enable Security Review inVercel Agent settings.

Get started with theSecurity Review documentation.
