Vercel Token Passnow includes $150 of tokens per month (up from $80) for the same $30 per team per month.

The credit applies to featured open-weight models served throughAI Gateway, including Kimi K3, Kimi K3.1 Pro, GLM 5.3, GLM 5.3 Flash, and DeepSeek V4.1 Flash.

Credit resets each billing period with no rollover. When it runs out, requests using standard AI Gateway keys or OIDC tokens fall back to the team's AI Gateway balance, while requests using Token Pass-scoped keys stop with no overage charges.

Token Pass is an Early Access add-on for Pro teams, with limited spots and a waitlist when they fill. To connect your coding agent, runvercel token-passin the Vercel CLI, or use a Token Pass API key if your agent supports AI Gateway.

Subscribe to Token Pass in yourAI Gateway dashboard.
