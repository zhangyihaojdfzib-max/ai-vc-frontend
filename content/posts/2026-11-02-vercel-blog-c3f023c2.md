Vercel now supportsvercel.toml, which allows you to to configure your project using theTOML configuration format. All of the same configuration properties are supported as invercel.json, but it supports comments and has a flatter structure.

All projects can now usevercel.toml. Use only one project configuration file: vercel.toml, vercel.json, or vercel.ts.
