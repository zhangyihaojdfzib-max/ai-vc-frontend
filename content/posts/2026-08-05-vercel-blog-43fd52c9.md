AI Gateway 现已在 AWS Marketplace 上线。

团队可通过其现有 AWS 账户采购 AI Gateway，将推理支出合并至 AWS 账单，并简化采购流程。购买以年度合同条款的私有报价形式提供，合同之外另按用量计费。

AI Gateway 通过单一端点为您提供一个 API 访问数百个模型。可靠性、成本控制与治理能力均已内置，包括自动故障转移、区域推理和零数据保留。您按提供商定价付费，无任何加价；通过 AWS 购买不会改变您每 Token 的支付价格。

查看 AWS Marketplace 上的列表以了解详情。
