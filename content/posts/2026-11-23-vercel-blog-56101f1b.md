AI Gatewaynow runs canary audits against inference providers to detect when prompt content is read outside the inference path.

Contractual Zero Data Retention (ZDR) agreements and point-in-time security audits establish how a provider should handle your data, but production infrastructure changes continuously. Canary audits add a detection layer on top.

Each canary audit run:

1. Mints unique URLs that exist nowhere else, each mapped privately to a specific provider, model, and audit run.
2. Sends prompts containing those URLs through the normal inference path, with ZDR requested for covered providers and non-ZDR pairs included as positive controls.
3. Watches for traffic. A ZDR provider should never retain, inspect, or crawl prompt content, so a canary URL should never receive a request.
4. Records any request to a canary URL, identifying the provider, model, and run for investigation.
