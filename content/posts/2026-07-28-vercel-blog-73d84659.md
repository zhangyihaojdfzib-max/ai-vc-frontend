Vercel Connect 现在允许你将连接器关联到自定义环境，这样该环境中的部署可以请求提供商令牌并接收转发的 Webhook。

当你在仪表板中为某个连接器添加或编辑项目时，自定义环境会与生产环境、预览环境和开发环境一同显示。

在 CLI 中，通过 `--environment` 参数传递环境标识符：

```
vercel connect attach slack/acme-slack --environment qa
```

仅在 qa 环境中关联 Slack 连接器。

传递 `--environment` 参数会替换默认环境。

关联后，该环境中的部署可以像往常一样使用 `getToken` 请求令牌。如果调用环境不在项目关联中，请求将失败并返回 `ClientNotEnabledForEnvironmentError` 错误。

触发器目标也可以指向自定义环境：

```
vercel connect attach slack/acme-slack --environment qa --triggers \  --trigger-environment qa --trigger-path /api/slack-events
```

将已验证的 Webhook 转发到 qa 环境。

在使用触发器指向自定义环境之前，请先部署到该环境并为其分配一个已验证的域名。Vercel Connect 会通过该域名转发事件。

项目关联控制哪些部署可以请求令牌，但在令牌发出后，它不会限制提供商令牌的使用。当环境需要提供商级别的隔离时，请为每个环境创建独立的连接器，并仅请求其所需的作用域。

Vercel Connect 在所有套餐中均处于 Beta 阶段。自定义环境在 Pro 和 Enterprise 套餐中可用。请从 Vercel Connect 快速入门指南开始，或阅读逐步指南。
