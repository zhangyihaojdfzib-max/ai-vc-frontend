A new Ignored Build Step preset lets you skip preview builds for branches without an open pull request. Production deployments and previews for branches with open pull requests continue to build.

On GitHub and GitLab projects, skipped preview deployments are canceled before consuming any Build CPU Minutes.

To enable this, open your project’sDeployments > Configuration. UnderIgnored Build Step, selectOnly build previews for pull requestsfrom theBehaviormenu and clickSave.
