# Cognizant 与 Anthropic 扩大合作，将 Claude 引入企业客户

我们正在扩大与 Cognizant（全球最大的技术服务公司之一）的合作关系。

Cognizant 在其为制造、生命科学、保险及其他行业客户构建和运行的系统中使用 Claude。随着我们合作的扩大，它正在将 Claude 嵌入其自身的业务和工程平台，作为其新 Frontier 认证员工模式的一部分，扩大 Claude 认证员工队伍，并成为 Claude 合作伙伴网络中的全球首要合作伙伴。

将 AI 成功整合到大型企业中，需要了解该公司的行业、其已运行的系统以及其运营所遵循的规则。Cognizant 带来了这些领域背景，以及工程深度和交付规模，将 Claude 带给全球企业。

### Cognizant 使用 Claude 进行构建

Cognizant 的工程师每天都在使用 Claude 进行构建，已有超过 30,000 名员工完成了 Claude 培训。

Cognizant 正在将 Claude 嵌入其多个平台，包括 Flowsource™、Neuro® AI Engineering 和 Neuro® IT Ops。其全栈工程平台 Flowsource 现在在其规范驱动开发模块中，让 Claude Code 与软件工程师协同工作。Flowsource 使用项目定义的规范、编码标准和架构蓝图来指导 Claude Code，然后在生产前评估输出。

### Cognizant 让 Claude 为客户工作

该公司利用其内部学到的经验来塑造如何将 Claude 带给客户，这项工作已经在进行中。其团队构建的示例包括：

- 为一家全球制造商在启动后六个月内构建的客户体验门户。
- 为一家生物制药公司构建的智能合同情报系统，在该部署中帮助将合同审查时间缩短了多达 40%，同时将提取准确率提升至 88% 以上。
- 一个风险导航工具，帮助核保人评估账户，过去需要数小时的手动研究，现在只需几分钟——在该部署中为每人每周节省约八小时。

"AI 能力的提升速度超过了企业吸收它的速度，这一差距是当前的决定性问题，"Cognizant 首席执行官 Ravi Kumar S 表示。"我们的角色是成为桥梁。我们带来行业背景、工程规模和信任框架，使用 Claude 在最苛刻的企业环境中交付生产成果。与 Anthropic 的合作正是为了那些需要可靠 AI（而不仅仅是实验性 AI）的客户而进行的。"

"深化与 Cognizant 的合作将帮助更多公司利用 AI 日益增长的能力，并以切实、实用的方式将其部署到其业务中，"Anthropic 联合创始人兼总裁 Daniela Amodei 表示。"从制造业到生命科学，Cognizant 正在将 Claude 引入一些全球最苛刻行业的日常工作中——这些正是 AI 能够为人类展现其最大价值的场景。"
