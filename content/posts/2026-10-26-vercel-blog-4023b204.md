Vercel Sandboxnow lets you send input to running commands through standard input (stdin).Use it to exchange messages with stdio MCP servers such asagent-browser, or send data to other command-line programs while they run.

In the TypeScript SDK, setstdin: trueanddetached: trueinrunCommand(). UsewriteStdin()to send input andcloseStdin()when you’re done:

```
1import { Sandbox } from '@vercel/sandbox';2
3const sandbox = await Sandbox.create();4const cmd = await sandbox.runCommand({5  cmd: 'cat',6  stdin: true,7  detached: true,8});9
10await cmd.writeStdin('hello');11await cmd.closeStdin();12
13const result = await cmd.wait();14console.log(await result.stdout()); 
```

Send input to a running command and read its output with the Sandbox TypeScript SDK.

You can also setstdinto a Node.js readable stream, such asprocess.stdin. The SDK forwards the stream’s data and closes the command’s standard input when the stream ends.

In the Python SDK, setstdin=subprocess.PIPEand send input withserver.stdin.send(). Callcommunicate()to close stdin, collect remaining output, and wait for the process to exit:

```

```
