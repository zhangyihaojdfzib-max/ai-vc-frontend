Black Forest Labs 在发布其 FLUX.1 图像模型时创造了历史。他们是首批率先实现快速、高质量、开源图像生成的独立研究实验室之一。如今，他们将目光投向视频领域，我们对此充满期待。

FLUX 3 是该实验室推出的全新多模态基础模型。与其他实验室相比，他们采用了一种新方法。BFL 开发了一个架构整合的模型，从图像、音频和视频中学习，以生成多模态输出。直接引用他们的发布博客：

“图像捕捉特定时间点的空间结构和关系。视频恢复了时间维度，揭示了时间动态和物理规律。音频揭示了视觉单独无法检测到的机械现象与声学之间的因果关系。语言将这些感知与目标、抽象概念和指令联系起来。

只学习其中一种，你得到的是对该投影的良好模型。同时学习所有模态，它们之间的相互约束会告诉你更多：声音必须与冲击匹配，运动必须遵循质量，未来必须从过去延续。模态不再彼此分离，而是成为关于同一底层现实的证据。”

显然，这种训练方法意味着该模型内置了更多物理规律。音频为运动提供信息，反之亦然。视频为已经编码了空间关系的图像引入了时间性。FLUX 3 是创建更好封装现实的权重网络的一次尝试。

## 运行FLUX 3

以下是如何用FLUX 3生成视频：

```
import Replicate from "replicate";

const replicate = new Replicate();

const output = await replicate.run(
  "black-forest-labs/flux-3",
  {
    input: {
      prompt: "A diver descends through crystal-clear turquoise water into a jungle cenote, sunbeams piercing down from the opening far above. Ancient glyphs carved into submerged temple walls, fish darting through fallen pillars. Hyper-realistic, 8k.",
      duration: "8",
      resolution: "720p",
      aspect_ratio: "16:9",
      generate_audio: true,
      // image: "https://...",        // start frame for image-to-video
      // end_image: "https://...",     // morph target, requires a whole-number duration
      // keyframe_images: ["https://...", "https://..."], // up to 10, storyboard mode
      // start_video: "https://...",    // continue an existing clip
    }
  }
);

console.log(output);
```
