Interfazebuilds models for deterministic work that general-purpose LLMs handle poorly: document processing, OCR, object detection, web scraping, speech to text, and classification.

As founder Yoeven Khemlani puts it, "Most models aren't deterministic by nature. That's fine when you're drafting an essay. But when a hospital or a legal team needs to process documents, you don't reach for an LLM." Ask an LLM for the total on an invoice and you get a number with no easy way to check where it came from. Interfaze's models return the number along with a bounding box showing where on the page it came from and a confidence score for how sure the model is. Every result can be checked, and the models still take prompts the way an LLM does.

Everything around Interfaze's models runs on Vercel, including the backend. That spans the API serving 50 million requests a month, the sandbox that executes code the model writes, and the routing that keeps data preprocessing running when a third-party model provider goes down.

## Copy link to headingThe backend required no infrastructure work

Interfaze's frontend and backend both run on Vercel. The backend handles every request to Interfaze's API, whether a customer is calling the model or uploading a file. All of it runs as serverless functions in the same codebase as the frontend. When a request needs computation, the model hands the code toVercel Sandbox, which runs it in isolation. There was no separate infrastructure to set up.

## Copy link to headingFluid compute handles the heavy jobs

Scalability was Yoeven's top requirement. The goal is serving the model to millions of users, andFluid computescales with traffic on its own. Heavier work runs there too. Vercel's memory and timeout limits are high enough that Interfaze's web scraping, which runs on Puppeteer, works out of the box.

## Copy link to headingAI Gateway makes model routing reliable at scale

Interfaze pushes large volumes of data cleaning through open source models hosted by third-party providers. A single provider is a weak link. Providers hit rate limits or go down, and when one does, the cleaning stops unless traffic moves somewhere else.

The providers are also not interchangeable. Two of them can claim to host the same open source model and serve it at very different quality.

When a provider fails or throttles,AI Gatewayfails requests over to the next provider automatically. It also lets Interfaze choose which provider serves a given model, so the team can run the same workload through each one, see which performs well, and send traffic there.

## Copy link to headingWorkflow SDK runs email sequences over months

Interfaze runs its lifecycle email system on theWorkflow SDK, with sends conditioned on product usage. The system tracks which API a customer called, at what volume, and how that compares against their first week. Retries are handled automatically, so one failed step doesn't take down the sequence.

The part Interfaze needed most was durable execution. A workflow can pause a step and pick it back up months later with its state intact, which the team found other systems could not do for long.

## Copy link to headingPreview deployments carry new model versions to customers

Interfaze runs more than one version of its model at a time, each at its own URL. When an error comes in, the team has to know which version produced the error before they can fix anything. On Vercel every URL is its own deployment with its own logs, so the error is already filed under the version that caused it. There was no separate logging vendor to set up.

Those same preview URLs are how a new model version gets to customers before it ships. The Vercel side of a release builds in about three minutes. Hosting the weights on GPUs is the slow part.

Interfaze recently releasedInterfaze 1 Lite, an open-weight version of its model that runs on a single GPU and is served through the same API. Next is a gateway for web search, one API that routes to whichever search provider a developer picks, the way AI Gateway does for models. It launches on the same Vercel backend as everything else.
