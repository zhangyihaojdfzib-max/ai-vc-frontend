Gemini 3.6 Flash 和 Gemini 3.5 Flash-Lite 现已在 AI Gateway 上可用。

Gemini 3.6 Flash 在编码、Agent（智能体）任务和 Web 开发方面提升了质量，同时消耗更少的 Token 并减少模型调用次数。它能生成更清晰的 Web 和应用开发输出。

Gemini 3.5 Flash Lite 升级了 Flash-Lite 层级的 Agent（智能体）能力，使其非常适合处理大型任务中特定范围的子 Agent（智能体）。

要使用它们，请在 AI SDK 中将模型设置为 `google/gemini-3.6-flash` 或 `google/gemini-3.5-flash-lite`：

```
1import { streamText } from 'ai';2
3const result = streamText({4  model: 'google/gemini-3.6-flash',5  prompt: '构建一个包含个人资料和通知部分的设置页面。',6});
```

AI Gateway 提供了一个统一的 API，用于调用模型、跟踪使用情况和成本，以及配置重试、故障转移和性能优化，以实现高于提供商自身的正常运行时间。它包含内置的自定义报告、零数据保留支持、API 密钥预算、路由规则等功能。

AI Gateway 反映提供商定价，不加价，并且不针对推理（包括自带密钥（BYOK）请求）收取平台费用。

在模型游乐场中试用 Gemini 3.6 Flash。
