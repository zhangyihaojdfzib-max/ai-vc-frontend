TheVercel CLInow includesvercel feedback, which sends bugs, friction reports, and feature requests to the Vercel team from your terminal.

```
1vercel feedback "The error didn't explain how to fix the issue"
```

Coding agents can also send feedback when they run into issues. Usevercel feedbackwith-for--fieldto include structured context askey=valuepairs. Repeat the flag to describe the task, expected behavior, and what went wrong.

```
1vercel feedback "The error did not explain the correct command" \2  -f product=cli \3  -f model=gpt-6-astra \4  -f harness=fx \5  -f task="deploy a preview" \6  -f expected="Create a Preview deployment" \7  -f actual="Unknown option: --preview" \8  -f type=bug9
10cat notes.md | vercel feedback -
```

Update to the latest Vercel CLI and read thevercel feedbackdocumentationto get started.
