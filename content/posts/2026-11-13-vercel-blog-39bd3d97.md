Vercel Daemonscan now send OpenTelemetry traces toVercel Tracing, allowing you and your agents to inspect background worker operations alongside the rest of your project's traces.

Vercel provides each daemon with a Unix socket for receiving OTLP/HTTP traces and sets the socket's path inVERCEL_OTEL_SOCKET_PATH.

Upgrading@vercel/otelto version 2.3.0 or later enables automatic trace export for Node.js daemons using the default configuration. The SDK detects this socket and sends the spans your worker records to Vercel.

```
1import { registerOTel } from '@vercel/otel';2
3registerOTel({ serviceName: 'my-daemon' });
```

Initialize OpenTelemetry before the worker starts.

These spans are available through theVercel CLI, which can search by service name within a project and return JSON for your agents.

```
1vercel traces search --project my-project --service my-daemon --json
```

Search daemon spans from the last hour as JSON.

Learn more in thedaemon tracing documentation.
