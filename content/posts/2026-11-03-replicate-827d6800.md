# Which MiniMax H3 model should you use?

- shridharathi

Run H3 Highspeed

MiniMax’s H3 family has three video models on Replicate:minimax/h3-highspeed,minimax/h3-lite, andminimax/h3. A 10-second clip at 768P costs $0.60, $0.40, or $0.80 depending on which one you pick. Our suggestion is to start with Highspeed, drop to Lite when you’re generating lots of options, and move up to H3 when you need 2K or the shot is hard.

Prices are from the model pages on October 31, 2026. At 2K, a 10-second H3 clip is $1.30.

The three share the same inputs otherwise. They all make clips from 4 to 15 seconds, and they all do text-to-video, image-to-video from a first and optional last frame, and generation guided by image, video, or audio references.

The example videos below come from the model pages. They use different prompts, and one of them starts from an image, so you can’t line them up as a fair comparison.

## Start with Highspeed

Highspeed is the one to iterate with. MiniMax pitches it as a balance between quality and speed, and it keeps the full set of reference inputs. It only outputs 768P.

A hummingbird hovers beside a bright orange hibiscus flower in a sunlit garden, wings a soft blur, shallow depth of field, slow push in

Text-to-video, 768P, 5 seconds. The run took 21 seconds. (See the run.)

References are where Highspeed earns its place. Say you’re making a short fashion spot and you have one image for the location, one for the character, and one for the bag. Tell the model what each image is for: which one sets the scene, which one is the character, and what has to stay the same from shot to shot. Then describe the action and the camera. There’s a full prompt for this further down.

## Use Lite when you want more attempts

Lite is the cheapest of the three, at $0.04 per second at 768P and $0.025 at 480P. Use it for storyboards, alternate openings, and any batch where you plan to throw most of the results away.

A hundred 10-second clips at 768P come to $40 on Lite, $60 on Highspeed, and $80 on H3.

Pick Lite to save money, not time. On the model-page examples, a 5-second Lite clip and a 5-second Highspeed clip both took about 21 seconds, though one run each proves very little and run time depends on the prompt and on load. Lite is also the model where you should look hardest at whether it did what you asked. A clip can look great and still have swapped the wrong object or dropped a character. If your batch involves fiddly edits, try a few on Highspeed first and see whether the difference matters to you.

## Choose H3 for demanding final shots

H3 is the top of the family, and the only one of the three that outputs 2K. It’s also the only one whoseresolutiondefaults to 2K, which matters if you’re watching costs.

the car revs through the desert

Image-to-video from a square first frame, 2K, 5 seconds. The output is 1440 × 1440 because it keeps the input image’s shape. The run took about three minutes. (See the run.)

Reach for H3 on motion graphics, choreographed effects, and edits where several things have to be right at the same time. Picture a logo animation where a dot turns into a letter, then an orbit, then the final mark. If one step is out of order or the text comes out misspelled, the clip is unusable. 2K won’t fix lettering for you, so check the text on every take.

The output keeps the shape of the input image, so a 4:3 still comes back at 1888 × 1440 and a 16:9 one at 2560 × 1440. The prompts mostly describe motion and camera. The image already covers what’s in the shot.

## Three prompts to try

### A fashion spot with four references

Use Highspeed. Pass four reference images in this order: the setting and mood, the character, the bag, the closing logo.

Create a 15-second, 16:9 fashion campaign. Use reference image 1 for the desert-road setting and restrained film texture, image 2 for the character, image 3 for the black bag, and image 4 for the closing logo. Beside a vintage car, the woman returns to the trunk, opens it, takes out the bag, briefly exchanges a look with the man by the car, and walks away. Keep the bag’s shape and the characters’ appearance consistent. Use purposeful cuts and a cool, understated mood. End on the supplied logo.

The bag is the thing to watch. If its shape drifts between cuts, the spot doesn’t work.

## Run Highspeed with the API

Install Replicate’s Python client, setREPLICATE_API_TOKEN, and run:

```
import replicate

output = replicate.run(
    "minimax/h3-highspeed",
    input={
        "prompt": (
            "A 10-second product film of an unbranded black travel bag "
            "on a pale stone pedestal. Begin with a close-up of the "
            "fabric texture, then slowly pull back to reveal the whole "
            "bag. Soft side lighting, restrained camera movement, "
            "consistent bag shape, no text or logos."
        ),
        "duration": 10,
        "ratio": "16:9",
    },
)

print(output)
```

For Lite, change the model tominimax/h3-liteand add"resolution": "768P"or"480P". For H3, useminimax/h3with"resolution": "768P"or"2K". Set it explicitly when you’re comparing, since H3 defaults to 2K and Lite defaults to 768P.

To start from an image, passfirst_frame_image, andlast_frame_imageif you want to pin the ending. For references, usereference_image_urls(up to 9),reference_video_urls(up to 3), andreference_audio_urls(up to 3). MiniMax requires an image or video reference alongside any reference audio. Each model’s API page lists the full set of inputs.

## Comparing them yourself

Run the same prompt, references, duration, and aspect ratio at 768P on all three, a few times each. Then score what your project cares about: whether the subject stays recognizable, whether the camera does what you asked, whether text comes out right. Time the runs separately from the length of the clips.

If you’re delivering at 2K, test H3 at 2K on its own terms. A 2K clip next to a 768P clip tells you which one you’d ship, not which model is better.
