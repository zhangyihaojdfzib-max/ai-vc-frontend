Vercel Container Registrynow supports compressed image layers of up to 2 GB each, up from 500 MB, the total image size limit stays 15 GB.

The registry works with standard workflows likedocker push,docker pull, anddocker tag, and pushing an image creates the repository on the fly.

```
1docker buildx build --push -t vcr.vercel.com/team/project/repository:tag .
```

Repositories can bemade publicfor read-only pull access by any Vercel team, orshared with specific teamsup to 100 from the dashboard or withvercel vcr permissions. The Vercel Managed Images that Vercel Sandbox runs on are served from ordinary public repositories, built with the same public-repository feature any team can use for its own images.

Manage repositories, images, and tags with thevercel vcrCLI commandsin Vercel CLI v58.3.0 or later, and log CI workflows in from GitHub Actions with thevercel/vcr-action/loginactionusing GitHub OIDC, which removes the need for long-lived registry credentials. If background optimization of a pushed image fails, the image shows an error status in the dashboard, and pushing the same image again retries the conversion.

See thedocumentationfor the full setup.
