Python 3.15 is now available as a Vercel Managed Image forVercel Sandbox.

To run a sandbox with Python 3.15, selectvercel/sandbox/python:3.15using theimageoption in either SDK or the--imageflag in the CLI.

```
1import { Sandbox } from '@vercel/sandbox';2
3const sandbox = await Sandbox.create({ image: 'vercel/sandbox/python:3.15' });4const version = await sandbox.runCommand('python', ['--version']);5console.log(`Python version: ${await version.stdout()}`);6

```

Create a sandbox with Python 3.15 and print its version.

The default universal image (vercel/sandbox/universal:latest) still ships Python 3.14 and is scheduled to switch to Python 3.15 on December 16, 2026.

Learn more in theVercel Sandbox images documentation.
