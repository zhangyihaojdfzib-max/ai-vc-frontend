Deployment summaries now show the size of the build cache each deployment saved and how close it is to the limit for itsbuild machine. The same information is in the CLI withvercel inspecton version 65.1.0 or newer, and in theget-deployment REST API endpoint.

Uploading the build cache is billable build time, and a cache that goes over the limit is discarded, so the next build starts without one.

This is on by default on all plans for deployments built on or after October 21. See themaximum build cache size for each build machinein the docs.
