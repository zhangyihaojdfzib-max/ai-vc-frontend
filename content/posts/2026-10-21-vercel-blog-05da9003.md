Deployments that Vercelautomatically skipsin a monorepo no longer count against your deployment rate limits. Teams with monorepos now get more deployments from the same limits.

Vercel skips a project's deployment when its source code and internal dependencies haven't changed, usingTurborepo's package graph and lockfile analysis to determine which projects a commit affects.

Skipping is enabled by default for new monorepo projects. You can turn it on for existing projects underBuild and Deploymentin theproject's settings.

Learn more aboutskipping unaffected projectsand deploymentlimits.
