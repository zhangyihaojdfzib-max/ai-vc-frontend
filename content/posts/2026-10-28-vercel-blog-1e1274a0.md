You can now run CI for your Turborepo with one line of configuration.

```
1{2  "tasks": {3    "lint": {4      "tags": ["ci"]5    }6  }7}
```

Use tags to make a task run in Vercel CI.

In Vercel's internal repositories, our wait time fromgit pushto "CI passed" is 2-6x shorter, dramatically improving our CI's ability to keep up with our coding agents.

To get started, prompt your agent in your repo:

Set up Vercel CI for this repository. Run `npx skills use vercel/ci@setup` and follow the skill's instructions to select initial tasks, configure Vercel CI, and open a pull request.

Each task marked with acitag runs on every push. Vercel CI automatically takes care of:

- Only running CI that is affected by your code changes
- Task caching withVercel Remote Cache
- Installing dependencies once per run
- Caching dependencies across code updates
