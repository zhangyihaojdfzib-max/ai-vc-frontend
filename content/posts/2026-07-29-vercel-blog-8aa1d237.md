AI Gateway 现已推出统一的快速模式抽象，目前处于测试阶段。

现在，您可以为 AI Gateway 上的每个模型以相同方式请求快速模式。将速度设置为 `fast`，网关会在可用时提供快速层级，并在不可用时回退至标准速度。

快速模式以更高的每 Token 成本换取更低的延迟或更高的吞吐量。您可以在任何可用位置使用它，无需绑定特定提供商或自行配置任何内容。

## 复制链接到标题 请求快速模式

在 `providerOptions.gateway` 下将 `speed` 设置为 `fast`，即可在可路由时将模型升级至其快速服务路径：

```
1import { generateText } from 'ai';2
3const { text, providerMetadata } = await generateText({4  model: 'anthropic/claude-opus-5',5  prompt: '用两句话解释量子计算。',6  providerOptions: {7    gateway: {8      speed: 'fast',9    },10  },11});12console.log('服务速度:', providerMetadata?.gateway?.routing?.speed);
```

您也可以直接使用快速标识符（如 `anthropic/claude-opus-5-fast`）来调用快速变体，这等同于在基础模型上设置 `speed: 'fast'`。

当您希望保留基础模型 ID 并在无法使用快速模式时回退至标准速度时，请使用 `speed` 选项。当您希望直接指定快速变体时（例如在 `gateway.models` 回退列表中），请使用快速标识符。`speed` 选项适用于所有 AI Gateway API 格式。

快速模式适用于越来越多的模型。您可以在 `models` 列表中通过标识符旁的闪电图标找到它们。对没有快速层级的模型请求快速模式不会产生任何效果，请求将以标准速度运行。模型的快速变体通常比基础模型更昂贵：请查看 `pricing` 了解更多详情。

## 复制链接到标题 在编码 Agent 中使用快速模式

在 Claude Code 中，完成 `setup` 后，使用 `/fast` 为 Anthropic Opus 模型切换快速模式。对于其他 Agent，请在模型配置中选择快速标识符，例如 `anthropic/claude-opus-5-fast`。

有关快速模式的更多信息，请阅读 `documentation`。
