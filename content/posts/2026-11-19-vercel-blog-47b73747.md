Coding agents can now usevercel help searchto find Vercel CLI commands by describing a task in plain language.

The search returns a list of matching commands. Add--with-helpto include the help page for the first result in the same call. For example,vercel help search "roll back production" --with-helpreturns the options and examples forvercel rollback.

Search also supports:

- API endpoints:When a Vercel API endpoint matches the task, search returns avercel apicommand with the request path and placeholders for every required input. The agent can fill in the values without guessing the path.
- JSON output:Use--jsonto return search results as JSON. Combine it with--with-helpto include usage instructions, options, and examples for the first result.

The CLI also includes a skill that tells coding agents to start withvercel help searchwhen looking for a command. Vercel doesn't log your search text.
