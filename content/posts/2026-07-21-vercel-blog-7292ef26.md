Vercel Connect 现在包含 100 多种服务的预设连接器，包括 Shopify、Resend、Sanity、Okta、Workday 和 Jira。

预设连接器是受支持服务的预定义配置。它们通过预填品牌名称、图标、认证类型以及 MCP 或发现 URL 来减少手动设置。与托管连接器不同，预设连接器不会将您的应用注册到外部服务。

## 复制链接到标题添加连接器

从 Vercel 仪表盘的连接器目录中选择一个预设。查看预填的配置，添加服务所需的任何凭据，然后创建连接器。

您也可以从 CLI 开始：

```
vercel connect create shopify --name acme-shop
vercel connect attach shopify/acme-shop --project my-app --environment production
```

使用 Vercel CLI 添加 Shopify 连接器

目前，vercel connect create 会打开仪表盘以完成设置。对预设连接器的完整 CLI 支持即将推出。

## 复制链接到标题请求令牌

附加预设连接器后，请求令牌的方式与任何其他 Connect 提供商相同。使用连接器的 UID（服务/名称）调用 getToken，以获取一个短期的、作用域限定的令牌：

```
1import { getToken } from '@vercel/connect';
2
3const token = await getToken('shopify/acme-shop', {
4  subject: { type: 'app' },
5  scopes: ['write_products'],
6});
7
8await fetch(`https://${shop}.myshopify.com/admin/api/2026-01/graphql.json`, {
9  method: 'POST',
10  headers: {
11    'X-Shopify-Access-Token': token,
12    'Content-Type': 'application/json',
13  },
14  body: JSON.stringify({
15    query: `mutation {
16      productCreate(product: { title: "Restocked: Acme Mug" }) {
17        product { id }
18      }
19    }`,
20  }),
21});
```
