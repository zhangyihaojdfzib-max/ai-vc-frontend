# 推出 OlmoEarth 嵌入：从 OlmoEarth Studio 导出自定义嵌入以进行下游分析

📄 技术报告：https://allenai.org/papers/olmoearth | 📊 文档：https://docs.olmoearth.allenai.org/embeddings | 💻 了解更多关于 OlmoEarth 的信息：https://allenai.org/olmoearth

![OlmoEarth 嵌入概念图：一个由数字嵌入值组成的网格，通过线条与地球上的点相连](/images/posts/dc322a9fe215.png)

OlmoEarth Studio 是我们用于构建地球观测模型的平台，现在支持计算和导出嵌入向量——由我们的开源 OlmoEarth 基础模型生成的地球观测数据的紧凑数值表示。源代码和模型权重与研究论文一同公开发布，社区可以准确检查这些嵌入的生成方式。

嵌入是利用 OlmoEarth 的一种快速且经济高效的切入点：它们支持广泛的下游任务，从相似性搜索到分割再到无监督探索。具有相似地表特征的区域最终会得到相似的向量；不同的区域则相距甚远。OlmoEarth 嵌入在我们自己的基准测试和独立评估中均表现出色。导出的云优化 GeoTIFF（COG）轻量且易于共享。通过 Studio 界面或 API 选择感兴趣的区域、时间范围、编码器变体、分辨率和影像源，即可获得一个可随意使用的 COG。如果您的应用需要更高性能，Studio 还支持监督微调（SFT）。

自定义计算的嵌入现已面向 OlmoEarth Studio 用户开放。如果您有兴趣获得访问权限，请联系我们。有关使用公开可用的 OlmoEarth 模型自行计算嵌入的说明，可在此处获取。

## 在 Studio 中计算嵌入

![OlmoEarth 嵌入世界地图，每个陆地像素按其 k-means 聚类着色，揭示跨大陆的连贯生物群落和土地覆盖结构](/images/posts/57462de00a1a.png)

基于 110 万个样本的季节性 Sentinel-2 影像生成的 OlmoEarth 嵌入中的全球结构。颜色表示 PCA 降维嵌入空间中的 15 个 k-means 聚类。

计算嵌入与 Studio 中任何其他预测的工作流程相同。首先配置模型并运行，然后下载结果。多个参数可定制输出：

- 感兴趣区域：绘制或上传任意多边形；Studio 负责影像获取和分块。
- 时间跨度：1-12 个月度周期。
- 编码器变体：Nano（128 维，140 万参数）、Tiny（192 维，620 万参数）或 Base（768 维，8900 万参数）。
- 空间分辨率：每像素 10 米、20 米、40 米或 80 米。
- 影像源：Sentinel-2 L2A、Sentinel-1 RTC，或两者兼有。

![同一嵌入栅格的四种假彩色渲染并排显示，每种渲染将嵌入波段映射为不同颜色](/images/posts/511700f5b0dc.png)

应用于同一嵌入栅格的不同可视化选项。

Studio 提供每个嵌入维度对应一个波段的 COG。向量以 8 位整数（int8）存储。值范围从 -127 到 +127，其中 -128 保留用于无数据。要恢复浮点向量，请使用 olmoearth_pretrain 中的 dequantize_embeddings。

由于所有内容都是按需计算而非从预计算的全球存档中提取，您的嵌入精确反映您关心的条件。您可以生成月度嵌入以捕捉季节动态，而不仅仅是年度快照。

## 您可以用 OlmoEarth 嵌入做什么

以下示例均使用 OlmoEarth-v1-Tiny（192 维）嵌入，分辨率为 40 米，使用 Sentinel-2 L2A 合成影像（大多数示例为年度合成；变化检测使用月度合成）。Tiny 是轻量级编码器，但性能仍然很高；对于您自己的应用，您可以将其替换为更大的变体，代价是更高的计算和存储成本。

### 少样本分割：标注景观

相似性搜索告诉您“哪里像这样？”，但有时您需要整个区域的离散标签。由于表示已经非常丰富，一个简单的线性分类器就可以从极少的标记像素生成全覆盖的土地覆盖图。

为测试这一点，我们在越南金瓯（一个沿海红树林区域）仅标注了 60 个像素（每类 20 个）。使用 ESA WorldCover 2021 作为三个类别（红树林、水体、其他）的标签来源，我们每类随机采样 20 个像素，训练了一个带逐特征标准化的逻辑回归模型，并预测了该区域的每个像素。

![越南金瓯 60 个标记像素的少样本分类：Sentinel-2 RGB、ESA WorldCover 参考图和预测的红树林/水体/其他地图，F1 为 0.84](/images/posts/dd24118c74e4.png)

从 60 个标记像素出发，分类器生成了一张连贯的地图，加权 F1 = 0.84。红树林、潮汐通道和开阔水域在整个区域被清晰勾勒。分类器快速饱和：从 30 个增加到 300 个标签，准确率几乎没有变化，因为嵌入承担了大部分繁重工作。

分析的核心是几行 Python 代码：

```python
import rasterio
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression


with rasterio.open("embeddings.tif") as ds:
    emb = ds.read().astype(np.float32)  

C, H, W = emb.shape
X = emb.reshape(C, -1).T  


clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000))
clf.fit(X[train_idx], labels[train_idx])
prediction = clf.predict(X).reshape(H, W)

```

这是一个线性探针，是基础模型的标准评估方法。一个 192 维的逻辑回归能从如此少的标签中恢复土地覆盖边界，这一事实意味着 Tiny 编码器在预训练期间已经组织了这些生态区分。更大的变体（Base，768 维）编码了更丰富的表示。

如果您有地面真实多边形、实地调查点或粗略的现有地图，您可以训练类似的分类器，为您自己的感兴趣区域生成全覆盖地图。

### 无监督探索：观察模型的所见

有时您没有查询位置或参考标签，只想了解嵌入中存在什么结构。主成分分析（PCA）是一种简洁的方法：降维至三个维度，映射为R/G/B，并显示为假彩色图像。相似的嵌入会自动获得相似的颜色。

![荷兰弗莱福兰的OlmoEarth嵌入结构：Sentinel-2 RGB影像与PCA假彩色图像（将PC1、PC2和PC3映射为红、绿、蓝），再现了圩田地块网格](/images/posts/58789d54fcd2.png)

荷兰的弗莱福兰是一片围海造田形成的圩田景观，拥有规则的农业地块网格。PCA假彩色图像以高保真度再现了这些边界。不同的作物类型、水体和城市区域各自呈现独特的色调。嵌入在从未被告知地块或作物是什么的情况下，内化了对景观结构的理解。

这种无监督视图是快速了解模型在您感兴趣区域内捕捉到何种结构的便捷方式。

## 更进一步：微调

本文中的示例均使用冻结嵌入，无需任务特定训练。嵌入是利用OlmoEarth的绝佳切入点：它们能够快速、经济高效地生成结果，在资源受限环境中表现良好，且易于共享。对于需要更高性能的应用，OlmoEarth Studio还支持SFT，即在您自己的标签上训练任务特定的模型头，其性能通常优于在冻结特征上的线性探测。

### 局限性

虽然我们一直在努力改进预训练方法，但使用上述某些技术检查嵌入在您的用例中的质量非常重要。性能还取决于输入影像的质量——持续云覆盖、大气伪影或合成期内缺失的观测都可能影响生成的向量。

Sentinel-2 L2A影像来自欧洲空间局，通过微软行星计算机访问。红树林参考使用ESA WorldCover 2021 v200。全球聚类可视化使用OlmoEarth-v1-Base（768维），采用季节性Sentinel-2合成影像，patch大小为8，在110万预训练样本上生成实例级嵌入。
