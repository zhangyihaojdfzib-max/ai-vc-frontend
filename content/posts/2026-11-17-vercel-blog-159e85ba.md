Speed Insightsnow measures soft navigations: client-side route changes that update page content without a full reload. This means you can now track performance as users move through your app, not just on full-page loads.

Speed Insights captures LCP, FCP, INP, and CLS for soft navigations and includes these measurements in your Real Experience Score. TTFB is not captured because there is no new document request.

Soft-navigation tracking is enabled by default for all projects using Speed Insights, with no action required. It works with modern web frameworks such as Next.js, SvelteKit, and Nuxt, in Chromium-based browsers.

In your project'sSpeed Insights dashboard, use the newNavigation Typefilter to viewAll,Hard, orSoftnavigation data.

Soft-navigation events count toward Speed Insights Plus usage.For existing projects that had Plus enabled before this release, Speed Insights events from soft navigations will not be charged until December 1.For projects that newly enable Plus, these events are billed from the start.

To disable soft-navigation tracking, setsoftNavstofalsein your application code and redeploy. This option requires@vercel/speed-insightsversion 2.1.0 or later:

```
1<SpeedInsights softNavs={false} />23injectSpeedInsights({ softNavs: false });
```

Disable soft-navigation tracking in your application.

Learn more in theSpeed Insights documentation.
