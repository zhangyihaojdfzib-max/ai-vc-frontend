AI Gateway 现已支持区域推理。在请求中设置 `inferenceRegion` 可将其固定至美国或欧盟区域。所有支持所选区域的模型提供商均以相同方式处理该请求。推理在该区域运行，提供商保留的任何数据也存储在该区域。

AI Gateway 支持两个固定区域，外加全局路由：

| 区域 | 推理运行位置 |
|------|--------------|
| 美国 | 美国数据中心 |
| 欧盟 | 欧盟数据中心 |
| 全局 | 任意区域 |

如果没有模型提供商能够处理该请求，则请求失败，而非在其他区域运行。每个响应都会报告处理该请求的区域，因此您可以确认每个请求的运行位置。

以下是一个使用 AI SDK 固定至美国的请求示例：

```
1import { streamText } from 'ai';
2
3const result = streamText({
4  model: 'moonshotai/kimi-k3',
5  prompt: 'Summarize this internal document.',
6  providerOptions: {
7    gateway: {
8      inferenceRegion: { scope: 'zone', geoRegion: 'us' },
9    },
10  },
11});
```

此前，有数据驻留或合规要求的团队必须为每个提供商单独配置区域路由，且无法可靠地确认请求实际运行位置。区域推理用一个在各处行为一致的字段取代了这种繁琐操作，并通过响应告知您每个请求的服务位置。

筛选 `model` 列表可查看美国或欧盟可用的模型，或从 `/v1/models` 读取 `regions` 数组。未设置 `inferenceRegion` 时，请求将全局路由，无驻留保证，因此驻留功能为自愿启用。

固定区域可能产生更高成本。提供商设定区域费率，通常比标准费率高出约 10%，AI Gateway 以原价传递，不加价。有关按提供商覆盖、响应验证、定价及 BYOK 行为，请阅读区域推理文档。
