You can now create custom monitors to get alerts based on yourVercel Observability queryresults.

For example, you can track signals such as AI Gateway costs, Core Web Vitals and other performance metrics, Workflow and external API failure rates, or Vercel Sandbox CPU time.

Each monitor tracks a single metric, such as response time, or a ratio of two metrics, such as errors divided by total requests. Choose statistical anomaly detection or a fixed threshold, then configure the detection window, filters, and grouping.

To create a monitor, inspect a chart’s query in Observability, start from a preset, or openSettings > Alertsfor your team.

You can also define a custom monitor in a JSON file and create it withvercel monitors addin theVercel CLI. Runvercel monitors schema --type customfor the schema and examples.

Receive alerts through email, Slack, Vercel Inbox, push notifications, or team-level webhooks. You can also add context forVercel Agentto use when investigating an alert.

Custom monitors are available on Pro and Enterprise plans with Observability Plus, at $0.0035 per GB of data scanned. Built-in alerts remain included with Observability Plus.

Create a custom monitoror learn more in theconfiguration documentation.
