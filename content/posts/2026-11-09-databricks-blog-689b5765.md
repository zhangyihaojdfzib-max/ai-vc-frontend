What is an MCP server in Databricks, and what does Sendoso's do?An MCP server exposes an external system's tools to agents. In Databricks it's installed as a governed MCP Service in Unity Catalog, and Unity Gateway controls which tools agents can call. Sendoso's MCP server makes its gifting tools available inside Genie One, so users can find a gift, send it, track it and see what it influenced without leaving Databricks.

Who is this for?Any team that sends gifts or direct mail: sales, customer success, RevOps, demand gen, field marketing, and customer or partner marketing. Users work in plain language in Genie One, with no code.

Can an agent do more than the user who is using it?No. Every tool runs as the signed-in Sendoso user, so it only sees what that user can see and only does what their role allows. Unity Gateway policies can restrict it further.

Is anything charged before I approve a gift?No. Sendoso first shows a preview of the gift, the recipient and the note. Nothing is charged until the user approves it, and Sendoso's budgets and campaign approvals apply just as they do in the Sendoso app.

Can I track or cancel a gift after it is sent?Yes. After a send, you receive a confirmation that includes a send ID, which you can use to track the gift in your Sendoso instance. You can cancel the gift up until it ships.
