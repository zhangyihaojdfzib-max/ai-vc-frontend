AgentEnv, Scale AI's framework for testing agents against tasks and scoring their results, now runs onVercel Sandbox. The Vercel provider ships in AgentEnv 0.9.1334 and later, and runs the agent and its task environment in separate Sandboxes.

Try theAgentEnv exampleto run an evaluation on Vercel Sandbox and inspect the task’s score and the agent’s recorded actions. After completing thesetup guide, run this command from the cloned repository. It uses your existing Vercel CLI login:

```
./vercel-eval --scope YOUR_TEAM --project YOUR_PROJECT
```

ReplaceYOUR_TEAMwith your Vercel team slug andYOUR_PROJECTwith an existing project name.

Learn more in theSandbox ecosystem documentation.
