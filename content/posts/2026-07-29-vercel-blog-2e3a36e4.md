xAI 的 Grok Voice Think Fast 2.0 现已在 AI Gateway 上线。这是一款语音到语音的语音模型，支持音频输入和音频输出，在推理、转录准确性和对话方面相比之前的 Grok Voice 模型有所改进。

该模型在说话的同时进行推理，因此可以在不增加延迟的情况下边思考边回答查询。它还经过训练，使用的推理 Token 比以前更少，因此工具调用触发更快，通常在 Agent（智能体）说完第一句话之前即可完成。转录在真实场景中表现良好，包括背景噪音和电话压缩环境。

通过 AI SDK 的实时 API 使用 `xai/grok-voice-think-fast-2.0`。在服务器上生成一个短期 Token，确保你的 API 密钥不会到达客户端：
