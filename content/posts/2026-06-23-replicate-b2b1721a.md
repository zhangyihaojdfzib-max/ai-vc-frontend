## 在 Replicate 上运行 Krea 2

### 在 Krea 2 模型之间进行选择

#### Krea 2 Large

Large 的规模是 Medium 的两倍多，且后训练更为柔和。其输出更原始、更具质感、也更灵活。当您最看重照片级真实感、颗粒感、运动模糊、低动态范围或表现力强的艺术风格时，请选择它。

#### Krea 2 Medium

Medium 体积更小、速度更快、成本效益更高。经过大量后训练，它在各代际间保持稳定和一致。对于插画、动漫、绘画以及其他需要可靠表现力的风格来说，它是一个不错的选择。

#### Krea 2 Medium Turbo

Medium Turbo 是速度最快的 Krea 2 模型。其蒸馏采样机制使其适用于低成本迭代、表现力插画、图形风格、字体实验以及快速活动或概念方向探索。

所有三种模型均可在 Replicate 上使用。以下是一个 JavaScript 示例：

```
import Replicate from "replicate";
const replicate = new Replicate();

const output = await replicate.run("krea-ai/krea-2-medium", {
  input: {
    prompt: "Close-up portrait, soft amber rim light, shallow depth of field, film grain",
    aspect_ratio: "4:5",
  },
});
console.log(output);
// => "https://replicate.delivery/..."
```

## 在 Cloudflare AI Gateway 上运行 Krea 2

如果你想在最快的 AI 网关上运行 Krea 2，请使用以下调用：

```
const response = await env.AI.run(
  'krea/krea-2-medium-turbo',
  {
    prompt: 'Ice citadel, frost mages and snow beasts, in a cool, fantasy anime style.',
    aspect_ratio: '1:1',
    resolution: '1K',
  },
)
console.log(response)
```

使用 `default` 让 Cloudflare 在首次认证请求时自动创建网关，或将其替换为现有网关的名称。通过网关的请求可以使用日志记录、缓存、速率限制等网关功能。Krea 是第三方模型，因此 Cloudflare 负责处理提供商凭据，并通过统一计费（Unified Billing）结算使用费用。你无需添加 Krea API 密钥。

你也可以通过 Cloudflare REST API 调用相同的模型：

```
curl -X POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run" \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "krea/krea-2-large",
    "input": {
      "prompt": "A quiet airport terminal at night, cinematic photography",
      "aspect_ratio": "16:9",
      "resolution": "1K"
    }
  }'
```
