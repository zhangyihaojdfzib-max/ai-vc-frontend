### Supporting a new HTTP method: QUERY

The new HTTP QUERY method is an IETF Proposed Standard, incidentally coauthored by our ownJames Snell,Â published in June 2026 asRFC 10008. A QUERY allows a client to send search criteria in a request body safely and idempotently without modifying server state. This makes it a good fit for AI search.

The adoption of QUERY is underway with major browser vendorsdiscussingÂ the RFC and multiple frameworks and clients either adopting (curlÂ andÂundici, for example), ordiscussingÂ adoption.

Search for Agents supports QUERY natively either using a plain text or JSON request body:

```
# Plain text
curl -X QUERY 'https://developers.cloudflare.com/.well-known/search' \
  --data 'What is the maximum payload size per ingestion request in Basin Pipelines?'

# JSON
curl -X QUERY 'https://developers.cloudflare.com/.well-known/search' \
  --header 'Content-Type: application/json' \
  --data '{"q":"How many bulk import requests per minute does Email Service allow?"}'
```
