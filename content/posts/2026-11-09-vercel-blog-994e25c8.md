Claude Fable 5.2fromAnthropicis now available onAI Gateway.

Fable 5.2 is built for open-ended technical work and improves on earlier Fable models in coding, reasoning, and vision. It can run long, ambiguous tasks unattended, and works as an orchestrator that hands simpler tasks to smaller models, or as an advisor that other Claude models consult on harder problems. It also communicates more clearly and generates output faster than earlier Fable models. Effort runs fromlowtomax, withhighas the API default.

Fable 5.2 has cybersecurity and biology safety classifiers enabled. Access to Claude Fable 5.2 requires data retention. Anthropic does not supportZero Data Retentionfor the model. Prompts and completions are retained for 30 days and are not used to train Claude. If your team has ZDR turned on, AI Gateway returns an error instead of sending the request to Fable 5.2.

To keep requests served when a classifier is triggered, usemodel fallbacks. Add amodelsarray toproviderOptions.gateway, and AI Gateway tries each model in order when the cybersecurity classifier declines a request.

Call it through theAI SDK, theChat Completions,Responses, andAnthropic MessagesAPIs, or acoding agentconnected to AI Gateway. Useanthropic/claude-fable-5.2as the model name:


This request falls back to Opus 5.5, then Sonnet 5.5, if the cybersecurity classifier declines it. Themodelsoption works the same way on every AI Gateway API format.
