# 推出 Aardvark：OpenAI 的 Agent（智能体）安全研究员

现已进入私有测试阶段：一个像安全研究员一样思考、并能规模化满足现代软件需求的 AI Agent（智能体）。

2026年3月6日更新：Aardvark 现已更名为 Codex Security，并以研究预览版形式提供。

Aardvark 现已直接内置到 Codex 中，成为 Codex Security，并通过 Codex 网页版向 ChatGPT Enterprise、Business 和 Edu 客户推出，下个月可免费使用。详情请参阅我们的博客⁠。

今天，我们宣布推出 Aardvark，一个由 GPT‑5 驱动的 Agent（智能体）安全研究员。

软件安全是技术领域最关键也最具挑战性的前沿之一。每年，企业级和开源代码库中都会发现数万个新漏洞。防御者面临着在对手之前发现并修补漏洞的艰巨任务。在 OpenAI，我们正致力于扭转局面，让防御者占据优势。

Aardvark 代表了 AI 与安全研究领域的一项突破：一个能够帮助开发者和安全团队大规模发现并修复安全漏洞的自主 Agent（智能体）。Aardvark 现已进入私有测试阶段，以在实际环境中验证并完善其能力。

## Aardvark 的工作原理

Aardvark 持续分析源代码仓库，以识别漏洞、评估可利用性、确定严重性优先级，并提出有针对性的补丁。

Aardvark 通过监控代码库的提交和变更，识别漏洞、分析其可能的利用方式，并提出修复建议。Aardvark 不依赖传统的程序分析技术，如模糊测试或软件组成分析。相反，它利用基于 LLM（大语言模型）的推理和工具使用能力来理解代码行为并识别漏洞。Aardvark 像人类安全研究员一样寻找漏洞：通过阅读代码、分析代码、编写并运行测试、使用工具等方式。

![标题为“AARDVARK — 漏洞发现 Agent 工作流”的图表，展示了从 Git 仓库到威胁建模、漏洞发现、验证沙箱、使用 Codex 进行修补，以及人工审核最终生成拉取请求的流程。](/images/posts/24df9c1aaa7a.jpg)

Aardvark 依赖一个多阶段流水线来识别、解释和修复漏洞：

- 分析：它首先分析整个仓库，生成一个反映其对项目安全目标和设计理解的威胁模型。
- 提交扫描：当有新代码提交时，它会针对整个仓库和威胁模型检查提交级别的变更，以扫描漏洞。当仓库首次连接时，Aardvark 会扫描其历史记录以识别现有问题。Aardvark 会逐步解释其发现的漏洞，并注释代码供人工审核。
- 验证：一旦 Aardvark 识别出潜在漏洞，它将尝试在一个隔离的沙箱环境中触发该漏洞，以确认其可利用性。Aardvark 会描述所采取的步骤，以确保向用户返回准确、高质量且低误报率的洞察。
- 修补：Aardvark 与 OpenAI Codex 集成，以帮助修复其发现的漏洞。它会为每个发现附上一个由 Codex 生成并经 Aardvark 扫描的补丁，供人工审核和高效的一键修补。

Aardvark 与工程师协同工作，集成 GitHub、Codex 和现有工作流程，在不减缓开发速度的前提下提供清晰、可操作的洞察。虽然 Aardvark 专为安全而构建，但在我们的测试中，我们发现它也能发现诸如逻辑缺陷、不完整修复和隐私问题等 Bug。

## 今天已产生实际影响

Aardvark 已服役数月，持续运行在 OpenAI 内部代码库以及外部 Alpha 合作伙伴的代码库中。在 OpenAI 内部，它已发现了一些有意义的漏洞，并为 OpenAI 的防御态势做出了贡献。合作伙伴强调了其分析的深度，Aardvark 能够发现仅在复杂条件下才会出现的问题。

在对“黄金”代码库的基准测试中，Aardvark 识别出了 92% 的已知和人为引入的漏洞，展示了高召回率和实际有效性。

## 面向开源的 Aardvark

Aardvark 也已应用于开源项目，在其中发现并负责任地披露了大量漏洞——其中十个已获得通用漏洞披露（CVE）标识符。

作为数十年开放研究和负责任披露的受益者，我们致力于回馈社区——贡献工具和发现，使数字生态系统对每个人都更安全。我们计划为选定的非商业开源仓库提供公益扫描服务，以助力开源软件生态系统和供应链的安全。

我们最近更新了⁠我们的⁠外部协调披露政策⁠，该政策采取了开发者友好的立场，侧重于协作和规模化影响，而不是可能给开发者带来压力的僵化披露时间表。我们预计像 Aardvark 这样的工具将导致发现越来越多的 Bug，我们希望以可持续的方式进行协作，以实现长期的韧性。

## 为何重要

软件现已成为每个行业的支柱——这意味着软件漏洞对商业、基础设施和社会构成了系统性风险。仅 2024 年一年，就有超过 40,000 个 CVE 被报告。我们的测试表明，大约 1.2% 的提交会引入 Bug——这些微小的变更可能产生巨大的后果。

Aardvark 代表了一种新的防御者优先模式：一个 Agent（智能体）安全研究员，通过随着代码演进提供持续保护来与团队合作。通过及早发现漏洞、验证实际可利用性并提供清晰的修复方案，Aardvark 可以在不减缓创新的前提下加强安全性。我们相信应该扩大安全专业知识的可及性。我们从私有测试版开始，并将在学习过程中逐步扩大可用性。
