You and your agents can now read and search the Vercel changelog feed from your terminal usingvercel changelog.

Coding agents can use this command to discover new Vercel products and features, find updates relevant to your project, and read full announcements to inform their recommendations.

vercel changelogreturns the latest five changelogs with full Markdown content. You can also set the number of results, search all changelogs using a keyword, and access JSON output for scripts and agents.

```
12vercel changelog3
45vercel changelog --limit 10 6
78vercel changelog search "AI SDK"9
1011vercel changelog --json
```

Update the Vercel CLI to version59.6.0or later and runvercel changelogto get started. Seevercel changelog --helpfor all available options.
