Instant deploymentslet you deploy eligible static sites to Vercel in about a second, without a build step. They now support CSS, images, fonts, and other assets alongside HTML and Markdown.

Deploy a landing page with its stylesheet and images, or a report created by your coding agent, through theVercel CLIorREST API. With the CLI, run:

```
1vercel deploy ./my-static-site2  Inspect         https://vercel.com/acme/my-static-site/8smhGjsosANjMqstetZ2CBb35fbB3  Preview         https://my-static-site-j7xexfrjw-acme.vercel.app4✓ Ready in 1s
```

Deploying a static site in one second with the Vercel CLI.

Newly supported file types include:

- Styles and data:CSS, JSON, XML, plain text, and web manifests
- Images:SVG, PNG, JPEG, GIF, WebP, AVIF, and ICO
- Fonts:WOFF, WOFF2, TTF, OTF, and EOT
- Documents and media:PDF, MP4, WebM, MP3, WAV, and OGG

Styles and data:CSS, JSON, XML, plain text, and web manifests

Images:SVG, PNG, JPEG, GIF, WebP, AVIF, and ICO

Fonts:WOFF, WOFF2, TTF, OTF, and EOT

Documents and media:PDF, MP4, WebM, MP3, WAV, and OGG

Instant deployments support up to 100 files totaling 25 MB or less. Vercel detects eligible deployments automatically, with no configuration required.

Deployments that exceed these limits, include JavaScript or other unsupported files, or are triggered by Git still build as before. The same applies to projects with a framework preset, custom build settings, a root-levelpackage.jsonor Vercel configuration file such asvercel.json, or apublic/directory.

This update is rolling out across all plans. Learn more in thedeployment documentation.
