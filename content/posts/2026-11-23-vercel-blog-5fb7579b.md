Vercel Flagscan now block a deployment from reaching production if you’ve declared a flag in code but haven’t created it in your project. Without that definition, your app can silently fall back to the flag’s default value, even if that turns on a feature you meant to keep off.

TheFlag Definitions PresentDeployment Checkruns when a deployment is ready. If any flags are missing, the check fails and lists them in the results, where you can create each one before redeploying.

The check reads yourFlags SDKdiscovery endpoint and requiresFLAGS_SECRETto be set in your project’s environment.

To turn on blocking, teams on all plans can enable the check in their project’sBuild and Deployment settingsand mark it as required. See theDeployment Checks documentationfor setup details.
