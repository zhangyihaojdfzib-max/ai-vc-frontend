Gemini 3.7 Flash（来自 Google）现已在 AI Gateway 上线，截至 2026 年 12 月 31 日可享五折优惠。

Gemini 3.7 Flash 在软件工程和 Agent 工作方面较之前的 Flash 模型有所改进。它能更可靠地解决问题，减少在失败的 Agent 循环中卡住的时间，这在长工具调用序列中尤为重要，因为一次偏离就会影响后续整个运行。它还能直接从设计稿生成桌面和 Web 应用代码，并且更贴近原始设计。

要在 AI SDK 中使用 Gemini 3.7 Flash，请将模型设置为 `google/gemini-3.7-flash`：

```
1import { streamText } from 'ai';
2
3const result = streamText({
4  model: 'google/gemini-3.7-flash',
5  prompt: '根据这个设计稿构建一个设置页面。',
6});
```

要在编码 Agent 中使用它，请运行 `vercel ai-gateway coding-agents setup` 连接 Claude Code、Codex、OpenCode 或 Pi，然后在 Agent 中选择 `google/gemini-3.7-flash`。

如果想无需代码体验 Gemini 3.7 Flash，可以在模型 Playground 中试用。

AI Gateway 提供统一 API，用于调用模型、跟踪使用情况和成本，并配置重试、故障转移和性能优化，以获得高于提供商自身的可用性。它内置自定义报告、零数据保留支持、API 密钥预算、路由规则等功能。

AI Gateway 反映提供商定价，不加价，且不对推理收取平台费用，包括自带密钥（BYOK）请求。
