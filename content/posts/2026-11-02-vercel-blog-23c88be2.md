Vercel MCPcan now show your deployments as an interactive card inside ChatGPT and other chat clients that supportMCP Apps.

The card shows live deployment status, build logs, and source and commit details, with a Visit button once the deployment URL is ready. You can send logs into the chat to debug with the model, or open the fullscreen view to read them beneath the card. For repositories linked to multiple projects, a project list lets you switch between them.

The card is Vercel MCP's first MCP App, built on the MCP Apps extension. Clients without app support receive the deployment state, preview URL, and commit as text instead. Theopen_deploymentstool looks up deployments by project, repository, or commit, with environment filtering. ChatGPT connects to Vercel MCP through itsConnectors setup.
