# LFM2.5-编码器：在CPU上实现快速长上下文推理

今天，我们在Hugging Face上发布了两款新的编码器模型：LFM2.5-Encoder-230M和LFM2.5-Encoder-350M。它们在质量上媲美更大的模型，同时随着输入变长仍能保持快速。这意味着你可以在现有硬件上运行文档级任务，甚至在CPU上也能做到。

以下是它们的特性：

- **同尺寸中表现强劲**：在GLUE、SuperGLUE和多语言任务上匹配或超越更大的编码器。
- **8,192 Token上下文**，且延迟随输入变长而缓慢增长。
- **CPU上快速**：在长上下文场景下，比ModernBERT-base快约3.7倍。

借助这些模型，你可以构建意图路由器、策略检查器、PII检测器和文本分类器，全天候低成本运行。请查看下方的在线演示。

## 为什么构建通用编码器

上个月我们发布了LFM2.5-Retrievers，专为多语言搜索而构建。LFM2.5-Encoders来自同一系列，但服务于更广泛的目的。它们使用掩码语言目标进行预训练，因此你可以对它们进行微调，用于分类、Token级任务和搜索。搜索只是编码器能做的事情之一。这就是为什么我们构建了一个通用模型，而不是复用检索器。

编码器驱动着许多现代生产级NLP应用：分类器、意图路由器、安全过滤器。这些任务全天候运行，通常在CPU上，处理越来越长的输入。BERT确立了这类模型，而最近的ModernBERT进一步提升了其准确性、速度和上下文长度。LFM2.5-Encoders在LFM2架构上迈出了下一步，其成本随输入增长而缓慢增加。

## 编码器的构建方式

我们从各自的LFM2解码器骨干网络初始化编码器：LFM2.5-230M和LFM2.5-350M。然后通过一些改动将每个因果解码器转换为双向编码器：

1. **双向注意力掩码**：每个Token现在可以看到两侧的Token，而不仅仅是它前面的。
2. **非因果短卷积**：我们对其进行对称填充，使得每个Token的卷积混合其两侧的邻居。
3. **掩码语言建模**：我们在训练期间掩码30%的Token。

![bidirectional_patches](/images/posts/5e3d44b79528.png)

我们分两个阶段训练这两个模型：

1. **通用语言能力**：在大规模网络语料库上，以1,024 Token上下文进行短上下文掩码语言目标训练。
2. **长上下文适配**：将上下文扩展到8,192 Token，使用完整数据混合，增强事实性、法律性和多语言能力。

## 如何使用和微调LFM2.5-Encoders

当你有一个高吞吐量的理解任务（如分类、路由、提取或评分），且该任务持续运行并需要保持低成本和高速度时，请使用LFM2.5-Encoder。对于这类任务，微调后的编码器比生成式LLM更小、更快、运行成本更低，并且适合你已有的CPU。

在两个编码器尺寸之间：

- **LFM2.5-Encoder-350M**：当准确性最重要时选择它。
- **LFM2.5-Encoder-230M**：当硬件资源更紧张或需要更高吞吐量时选择它。

你可以用几行代码开始。使用transformers加载模型。然后直接运行它进行掩码Token预测，或者附加你自己的头部并针对你的任务进行微调。

### 加载并运行模型

安装最新版本的transformers：

```shell
pip install -U transformers

```

运行掩码Token预测：

```py
from transformers import AutoModelForMaskedLM, AutoTokenizer
import torch

model_id = "LiquidAI/LFM2.5-Encoder-230M"  
tok = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)
mlm = AutoModelForMaskedLM.from_pretrained(model_id, trust_remote_code=True)

text = f"法国的首都是{tok.mask_token}。"
enc = tok(text, return_tensors="pt")
with torch.no_grad():
    logits = mlm(**enc).logits
pos = (enc["input_ids"][0] == tok.mask_token_id).nonzero()[0].item()
print([tok.decode([t]).strip() for t in logits[0, pos].topk(5).indices.tolist()])


```

对于下游任务，加载编码器主体并附加你自己的头部（分类、Token分类、回归、检索）：

```py
from transformers import AutoModel

body = AutoModel.from_pretrained(model_id, trust_remote_code=True)

```
